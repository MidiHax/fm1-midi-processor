Flash firmware

Install the FM-1 MIDI Processor firmware on an M-VAVE FM-1 over USB, from this page. It takes about a minute.

Before you start
  • Use desktop Chrome or Edge. Firefox and Safari can't send the SysEx this needs.
  • Connect the FM-1 with a USB data cable, straight to the computer, and switch it on.
  • Close anything else using the FM-1's MIDI port: a DAW, MIDI-OX, other updater pages. Windows lets only one program open it.
  • Replacing the stock firmware erases its projects, voices and samples. Back them up first if you want them.

This page speaks the FM-1's own update protocol (from the FM1 Open SDK's browser updater, over USB MIDI SysEx). It checks the package's checksums, the device's identity and, after the restart, the installed build. Nothing is sent anywhere except to the FM-1. To go back to the stock firmware, use M-VAVE's own updater.
