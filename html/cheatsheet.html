  • Tap to turn a search on or off. Its LED is lit and SRCH shows in the title.
  • Hold (about 1 s) to open its settings. HOME goes back.
  • Searches combine. They only hide rows on screen and never affect MIDI.

Rule Builder (GLO): IN from one msg, OUT from another

  1. HOME Select the incoming note. Press F5 to set IN.
  2. GLO back. Select the target note and press G5 to set OUT.
    Or: ARP, play the note, then press LFO.
  3. Press REC REC. The rule joins its Message Remap list (ADDED) and the scratchpad clears.

Rule pages

Message Remap FX

  • One list per port + CH + TYP (NOTE, CC, PC).
  • PLAY on a rule opens it. On + NEW RULE it adds one.
  • REC×2 deletes (list) or saves (Add Rule).
  • NOTE rules also remap Note Off, so notes never hang.

Channel Remap

  • Moves a port's whole channel, after message rules. PLAY / REC as above.

Event Triggers SEL

  • PLAY opens a trigger, or adds one from + NEW TRIGGER.
  • Edit Trigger: PLAY opens its messages; REC test-sends them. Edits apply at once.
Pipeline: Channel Filter → Message Filter (per port) → Message Remap → Channel Remap → USB OUT Limits: 16 patches · 32 rules per list, 256 per patch · 32 channel rules · 32 triggers · 100-message history
